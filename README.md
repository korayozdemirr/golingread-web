# 📚 GoLingread

**GoLingread** is an interactive, comprehensible input-based English learning web application. It helps users learn English naturally by reading stories with a targeted 95%+ comprehension rate.

---

## ✨ Key Features

- 📖 **95% Comprehension Matching:** Read stories tailored precisely to your vocabulary level.
- 💡 **Instant Click-to-Translate:** Hover or click any word for contextual Turkish translation and pronunciation.
- 📊 **Smart Vocabulary Tracking:** Save unknown words automatically and practice with spaced repetition.
- 🎧 **Audio & Shadowing:** Listen to natural audio while reading.
- 🎨 **Distraction-Free UI:** Clean, modern reading interface optimized for focus.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js / React / Tailwind CSS
- **Backend:** Node.js / Supabase
- **AI Integration:** OpenAI / Gemini API (Story generation & word context)

---
